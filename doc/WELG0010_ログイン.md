# 画面設計書: ログイン

| 項目 | 内容 |
| --- | --- |
| ファイル名 | `WELG0010_ログイン.md` |
| 画面ID | WELG0010 |
| 対応 | `管理画面モック.pdf` 2ページ |
| 画面名 | ログイン |
| 技術 | React 18、関数コンポーネント、Hooks、Next.js 14（App Router）、Redux、TypeScript |

この文書だけで、ログイン画面の見た目を実装できること。認証処理は対象外。

この画面の色、余白、文字サイズ、太さは、この設計書の数値を使う。共通部品に付け替えるときは `doc/共通部品.md` に従い、部品とこの画面の両方で指定しているプロパティは、そこに書いた CSS 変数へこの設計書の数値を代入する。部品が指定していない幅や位置は、この設計書の数値を通常の CSS で書く。

## 印の意味

- 【不明】PDFにも別要件にも確定値がない。実装で文言や動作を足さない。
- 【仮】画面を置くためにこちらの設計で決めた値。PDFには無い。

## 作る範囲

- 画面中央のログインカードを表示する。
- メールアドレス欄とパスワード欄は、ユーザーが文字を入力できる枠にする。
- PDF上の欄内の文字は、未入力のときだけ見える案内にする。
- 値を入力しているあいだは黒文字にする。パスワードは黒丸にする。
- パスワード欄とログインボタンのあいだに、エラー文言を出す領域を要素として最初から置く。余白だけでは作らない。

## 作らない範囲

- 認証の成否判定、セッション作成、画面遷移。ログインボタンからエラー状態へは切り替えない。
- エラー文言の領域と、出す文言・色は作る。認証が失敗したときにその領域へ出す。
- パスワード再設定、アカウント作成。PDFに該当UIは無い。
- サイドメニュー、サンプルデータバッジ。このページには無い。
- `(console)` レイアウトの子にすること。この画面では `AdminShell` をマウントしない。

## 画面の置き場所【仮】

PDF に URL は無い。

| 種別 | 仮のパス |
| --- | --- |
| ルート | `/login` |
| ページ | `src/app/login/page.tsx` |
| 画面本体 | `src/features/login/LoginView.tsx` |
| 型 | `src/features/login/types.ts` |
| state | `src/features/login/loginSlice.ts` |

`page.tsx` は Server Component とし、`"use client"` の `LoginView` を置く。置き場所は `src/app/login/page.tsx` のままにし、`src/app/(console)/` の下には置かない。

ログイン済みかどうかでリダイレクトする処理は作らない。判定条件は【不明】。

## レイアウト

サイドメニューは置かない。画面全体は薄いグレーにする。タイトルから注釈までの塊を、画面の上下中央かつ左右中央に置く。

色、余白、文字サイズ、角丸は、PDF 2ページ目（1080×600）から測った暫定値を次節に置く。PDFにこの数値の指定は無い。

```text
        管理コンソール
        外国人向け日本語学習アプリ

        +---------------------------+
        | ログイン                  |
        | メールアドレス            |
        | [                      ] |
        | パスワード                |
        | [                      ] |
        |                           |
        |  ここにエラー文言を出す   |
        |  （無いときも同じ高さ）   |
        |                           |
        | [ ログイン              ] |
        +---------------------------+

        アカウントをお持ちでない場合は、運営管理者にお問い合わせください。
```

この領域は高さ 40px の要素にする。エラー文言が無いときも、同じ 40px を描画する。margin で間隔を空けるだけでは足りない。文言の有無で、入力欄・ボタン・注釈の位置は変えない。

上のアプリ名はカードの外、中央寄せ。注釈もカードの外、中央寄せ。

## 見た目の暫定値

PDF 2ページ目の画像と、文字の位置・サイズから測った値。実装で合わせるための暫定であり、指定値ではない。1px 単位に丸めている。小数だった実測は、表の実測列に残す。

基準は、モック画像の 1080×600 をそのまま px とみなす。これより狭い画面での折り返しは、このページからは測れない。

### 色

| 対象 | 暫定 |
| --- | --- |
| 画面背景 | #F4F5F9 |
| カード背景 | #FFFFFF |
| 見出し、ラベル | #1B2430 |
| サブタイトル | #5B6675 |
| 注釈 | #5F6772 |
| 入力欄の枠線 | #919CA8 |
| 入力欄の中の案内文字（未入力時のみ） | #757575 |
| 入力中の文字 | #000000 |
| 入力欄の背景 | #FFFFFF |
| エラー文言 | #C62828 |
| ログインボタンの背景 | #2B4C9B |
| ログインボタンの文字 | #FFFFFF |

カードの外側に、ごく薄い影がある。見た目は 1〜2px 程度の #DEE4EA。暫定は `0 1px 2px #DEE4EA`。ぼかしの厳密な値は画像からは割り切れない。カードに枠線は付けない。

画面のルートの文字色は #1B2430。`color-scheme` は `light`【仮】。OS のダーク表示で、背景と文字色を置き換えない。フォントは画面全体の `Arial, Helvetica, sans-serif` を継承する。入力欄とボタンも同じ書体を継承する。

### 文字サイズ

文字レイヤーのサイズを使う。フォントファミリー名は取れていない。

| 対象 | 暫定 | 実測 |
| --- | --- | --- |
| 管理コンソール | 18px | 18px |
| 外国人向け日本語学習アプリ | 10px | 9.75px |
| カード内の「ログイン」 | 14px | 13.5px |
| メールアドレス、パスワードのラベル | 10px | 9.75px |
| ログインボタンの文字 | 11px | 10.5px |
| 注釈 | 9px | 9px |
| 入力欄の文字（入力した値と未入力の案内） | 10px | 文字レイヤーに無い。灰色文字の高さは約 9px |

メールアドレスとパスワードのラベルは 10px のまま、太字にする。`font-weight` は `bold`。文字レイヤーから太さは取れていない。

「管理コンソール」は 18px のまま、カード見出しの「ログイン」は 14px のまま、同じく `font-weight: bold` にする。ログインボタンの「ログイン」は太くしない。

入力欄の文字サイズは、入力した値と未入力の案内で同じ 10px にする。PDF の欄内の灰色文字に揃える。文字レイヤーには無い。パスワード欄の灰色「パスワードを入力」の文字の高さは約 9px で、ラベルの文字レイヤー 9.75px と同じ系統。16px は、文字が切れないように仮に置いたサイズであり、ここでは使わない。

行高は 14px。案内も入力値もこのサイズに揃える。改行はしない。幅を超えても折り返さず、1行のままにする。入力欄の高さは枠込み 32px のまま。10px、行高 14px なら、この中で文字の上下は切れない。

エラー文言のサイズは PDF に無い。暫定は 12px、行高 16px。色の `#C62828` も、赤文字にするための暫定であり、PDFから測った値ではない。

サブタイトル、注釈、入力した文字、未入力の案内、ログインボタンは太字にしない。`font-weight` は `normal`。

行高は次のとおり。入力欄とエラー文言は、上に書いた値と同じ。

| 対象 | 行高 |
| --- | --- |
| 管理コンソール | 18px |
| サブタイトル | 10px |
| カード見出し | 14px |
| ラベル | 10px |
| 入力欄（入力値と案内） | 14px |
| エラー文言 | 16px |
| 注釈 | 9px |
| ログインボタン | 32px |

ボタンの行高は、高さ 32px の中で 11px の文字を上下中央に置くため。ボタンの padding は 0、枠線は無し。

### 角丸

| 対象 | 暫定 | 測り方 |
| --- | --- | --- |
| カード | 8px | 角の曲線が、端から約 8px で直線になる |
| 入力欄 | 6px | 上辺の直線が、左右の端より約 6px 内側から始まる |

### 余白

タイトルから注釈までの塊を、画面の上下中央かつ左右中央に置く。上端から 128px、注釈下端 473px は、高さ 600px のモックでの実測であり、配置の指定には使わない。

| 対象 | 暫定 | 実測 |
| --- | --- | --- |
| カード幅 | 312px | 312.5px |
| カード左右の内側余白 | 24px | 約 24px。入力欄とボタンの左右端が、カード端からこの位置 |
| カード上端から「ログイン」の文字上端 | 28px | 27px |
| 「ログイン」の文字下端からメールアドレスラベル上端 | 22px | 22px |
| ラベル下端から入力欄上端 | 8px | 約 7px。メール欄とパスワード欄で同じ |
| メール入力欄の下端からパスワードラベル上端 | 20px | 約 19px |
| パスワード入力欄の下端からボタン上端 | 40px | 約 17px。エラー文言の表示領域として、実測より広げる |
| ボタン下端からカード下端 | 24px | 約 24px |
| 入力欄の幅 | 264px | 約 264px |
| ログインボタンの幅 | 264px | 入力欄と左右を揃える。カードの外枠までは広げない |
| 入力欄の高さ | 32px | 枠を含めて約 32〜34px |
| 入力欄の左右内側余白 | 10px | 枠の内側から案内文字まで約 10px |
| ボタンの高さ | 32px | 約 31px |
| タイトル下端からサブタイトル上端 | 12px | 11.6px |
| サブタイトル下端からカード上端 | 22px | 22.4px |
| カード下端から注釈上端 | 22px | 21.9px |
| 入力欄の上下内側余白 | 8px | 【仮】。枠線 1px、高さ 32px のとき、行高 14px が内容の高さになる |
| タイトルから注釈までの塊の幅 | 312px | カード幅と同じ【仮】。この幅の中で中央寄せする |

パスワード欄の直下に、高さ 40px の表示領域を必ず置く。ログインボタンはその直下に置く。40px は暫定。PDFの間隔は約 17px なので、カードは実測より約 23px 高くなる。

この 40px は要素の高さであり、上下の margin を足して作らない。中身が空でも高さは 40px のままにする。文言は領域の上下中央、1行。「IDまたはパスワードが正しくありません」は、幅 264px、12px ならこの中に収まる。

注釈は折り返さない。1行のままにする。

未入力の案内の `opacity` は 1。ブラウザの初期値で #757575 を薄くしない。

エラー文言は折り返さない。幅 264px を超えるときは、40px の領域の中で隠し、高さは変えない。

```ts

  heading: string;
  emailLabel: string;
  emailPlaceholder: string;
  passwordLabel: string;
  passwordPlaceholder: string;
  errorMessage: string;
  submitLabel: string;
  note: string;

```

Redux に置くのは、初期表示用の文言だけ。slice 名は `login`。reducer は作らない。認証 action は作らない。

入力中の文字列と、エラーを出しているかは `LoginView` の `useState` に置く。入力値の初期値は両方とも空文字。store へ書き戻さない。エラー表示の初期値は出さない。

## 初期データ

```ts
{
  screenId: "WELG0010",
  appName: "管理コンソール",
  appDescription: "外国人向け日本語学習アプリ",
  heading: "ログイン",
  emailLabel: "メールアドレス",
  emailPlaceholder: "name@example.com",
  passwordLabel: "パスワード",
  passwordPlaceholder: "パスワードを入力",
  errorMessage: "IDまたはパスワードが正しくありません",
  submitLabel: "ログイン",
  note: "アカウントをお持ちでない場合は、運営管理者にお問い合わせください。"
}
```

`name@example.com` と「パスワードを入力」は、未入力のときにだけ `placeholder` として見せる。値は入れない。1文字でも入った欄では案内を消す。文字をすべて消すと、案内を戻す。

案内の色は #757575。入力した値の色は #000000。

## 項目

| 表示 | 種別 | 実装 |
| --- | --- | --- |
| 管理コンソール | 見出し | `appName`。18px、太字 |
| 外国人向け日本語学習アプリ | 補足 | `appDescription` |
| ログイン | カード見出し | `heading`。14px、太字 |
| メールアドレス | ラベルと入力欄 | `emailLabel`。10px、太字。単一行。`type="text"`。`value` は入力値。未入力時の案内は `emailPlaceholder` |
| パスワード | ラベルと入力欄 | `passwordLabel`。10px、太字。単一行。`type="password"`。未入力時の案内は `passwordPlaceholder`。入力中の文字は黒丸 |
| エラー文言 | 最初から置く表示領域 | パスワード欄の直下、ボタンの直上。高さ 40px の要素。空でも高さは変えない。出すときは `errorMessage` |
| ログイン | ボタン | `submitLabel`。幅は入力欄と同じ 264px。背景は青、文字は白 |
| 注釈 | 本文 | `note` |

メール欄の `autoComplete`、`inputMode`、最大文字数は【不明】。属性は付けない。パスワードの表示切替ボタンは作らない。

`form` で囲むか、ボタンの `type="submit"` にするかは【不明】。Enter キーで送信しないため、`form` は置かず、ボタンは `type="button"` にする。

## 入力とエラー表示

両方の欄は、最初は空にする。

| 状態 | メールアドレス欄 | パスワード欄 |
| --- | --- | --- |
| 未入力 | 案内 `name@example.com` を #757575 で見せる | 案内「パスワードを入力」を #757575 で見せる |
| 入力中 | 入力した文字を #000000 で見せる。案内は消す | 入力した文字を黒丸で見せる。案内は消す |
| 再び空 | 案内を戻す | 案内を戻す |

パスワード欄は `type="password"` にする。黒丸の字形はブラウザの標準でよい。色は入力文字と同じ #000000。

エラー領域は、パスワード欄の直下、ログインボタンの直上に、最初から要素として置く。高さは 40px で固定する。左右の端は入力欄と揃える。文言は領域の上下中央に置く。左端は入力欄の左端と揃える。領域の外に margin を足して、この高さを代用しない。

| 状態 | 領域の中 | レイアウト |
| --- | --- | --- |
| エラーなし | 文字を出さない。領域そのものは 40px で描画する | 入力欄とボタンの位置は初期表示のまま |
| エラーあり | 「IDまたはパスワードが正しくありません」を #C62828、12px、1行で、領域の上下中央に出す | 入力欄、ボタン、注釈の位置はエラーなしのときと同じ |

エラーありにする処理は、この画面のボタンには付けない。認証処理が失敗したときに、この文言をこの領域へ出す。別の失敗文言は、この仕様では出さない。

## 受け入れ条件

- `/login` にサイドメニューとサンプルデータバッジが無い。`AdminShell` はマウントされない。

- メール欄へ文字を入れると #000000 になり、案内は消える。すべて消すと案内が戻る。

- ログインボタンの幅は入力欄と同じ 264px で、左右の端が揃う。
- タイトルから注釈までの塊は、画面の上下中央にある。上端からの固定距離では置かない。
- 「管理コンソール」は 18px の太字。カード見出しの「ログイン」は 14px の太字。メールアドレスとパスワードのラベルは 10px の太字。入力欄の案内と入力値はどちらも 10px、行高 14px で、1行のまま、文字の上下が切れない。

- 認証用の API 呼び出しや Redux のログイン action が無い。
- サブタイトル、注釈、入力した文字、未入力の案内、ログインボタンは太字ではない。
