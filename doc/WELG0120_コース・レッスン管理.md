この文書だけで、コース・レッスン管理の見た目と、一覧のデータ描画を実装できること。保存、公開、追加、紐づけの処理は対象外。

## 印の意味

- 【不明】PDFにも別要件にも確定値がない。実装で文言や動作を足さない。
- 【仮】画面を置くためにこちらの設計で決めた値。PDFには無い。

## 作る範囲

- 右側だけを表示する。画面IDは `WELG0120`。左側の紺領域は描画しない。
- レッスン一覧と、レッスン編集欄を表示する。
- 一覧、コースの選択肢、公開状態の選択肢、紐づく問題集は、渡された配列の件数だけ描画する。
- 編集欄の文字は、画面内の state で変更できる。保存ボタンでは store へ書き戻さない。
- 動画の再生枠は、幅 390px、高さ 219px の空きとして常に置く。中身は動画を出していないときの見た目にする。

## 作らない範囲

- コース追加、レッスン追加、問題集の紐づけ、下書き保存、公開、の処理と遷移。
- 行クリックで編集対象を切り替える処理。PDFにその説明は無い。
- コースのドロップダウンを変えたときに一覧を絞り込む処理。
- 動画の再生。上の「動画URL（YouTube）」に URL が入ったとき、直下の紺の枠の中へ動画を出す想定にする。今回はプレイヤーも `iframe` も置かず、その枠のスペースだけ確保する。

## 見た目の暫定値

PDF 3ページ目の画像と、文字の位置・サイズから測った値。実装で合わせるための暫定であり、指定値ではない。1px 単位に丸めている。

このページのキャンバスは 595.28×841.89 で、1ページ目の 1080px 幅より小さい。同じ UI を縮小している。倍率は 1080 / 595.28 = 1.815。以下の px は、ページ上の座標と文字サイズに 1.815 を掛けて、1080px 幅の画面に揃えた値。高さは 1ページ目の 825px とは別で、換算後は約 1528px になる。

左側の紺領域の色、文字サイズ、角丸、余白は WELG0110 と同じ。このページでも、換算後のサイドバー幅は 180px、背景 #1C2431、選択中 #2B4C9B、本文左端 211px だった。

管理者名の上に、高さ 1px の直線を付ける。色は `#374051`。左 12px、右端 168px。選択中メニューと同じ左右位置。名前の上端より 15px 上。文字には重ねない。

ログアウトの文字に下線を付ける。`text-decoration: underline`。色は `#CED6E3` のまま。太さは通常。

左側の間隔は、この画面でも次のとおり。

## Redux

slice 名は `courseLesson`。初期 state にサンプルを置く。reducer は作らない。追加、保存、公開、紐づけ、選択変更の action は作らない。

一覧と選択肢は `useAppSelector` の配列をそのまま `map` する。

編集欄に表示したあとの文字変更は `CourseLessonView` の `useState` に保持する。初期値は `lessonDraft` をコピーする。保存ボタンを押しても、この state を slice へ戻さない。

コースの選択肢は、画像で見えた1件だけを入れる。他のコース名は【不明】なのでサンプルに足さない。

## 描画ルール

| 領域 | ソース | 増減 |
| --- | --- | --- |
| コースの select | `courseOptions` | `option` を件数分出す |
| レッスン一覧 | `lessons` | 行を件数分出す。6行固定にしない |
| 公開状態の select | `publishStatusOptions` | `option` を件数分出す |
| 紐づく問題集 | `lessonDraft.linkedQuestionSets` | バッジを件数分出す |

一覧の各行は、左に `orderNumber` と `name`、右に状態バッジ。列見出しとして確定しているのは、編集欄側の「レッスン名」だけ。一覧側に「番号」「状態」という見出しを新たに付けない。PDFの一覧に明確なヘッダ行は無い。

0件の案内文は【不明】。一覧が空なら行を出さず、「レッスンを追加」ボタンと見出し「レッスン一覧」は残す。問題集が0件ならバッジを出さず、ラベル「紐づく問題集」とボタン「問題集を紐づける」は残す。

動画URLの下に、固定で次の文を出す。

```text
URLを入力すると、アプリの学習画面に動画が埋め込まれます。
```

紺の矩形は、動画を再生する枠である。上の「動画URL（YouTube）」に URL が入っているときは、この枠の中にその動画を出す想定。URL が空のときは、枠の中に動画を出さない。

動画を出していないときは、枠の中に再生マークと、次の固定文を出す。

```text
動画プレビュー（URL入力後に表示）
```

動画を出しているときは、再生マークとこの文を消し、同じ枠の中を動画に差し替える。枠の幅 390px と高さ 219px は、どちらの状態でも同じにする。枠の外にある補足文、公開状態、表示順、レッスンの説明、問題集のバッジ、ボタンの位置は動かない。

今回の実装は、この差し替えを作らない。URL 欄が空でも、サンプルの URL が入っていても、枠の中は動画を出していないときの見た目のままにする。プレイヤーも `iframe` も置かない。URL の文字列を動画として認める形式は【不明】。形式の判定も再生も作らない。

選択行の背景はデータの `selected` に従う。行に `onClick` は付けない。編集欄の初期値を、選択行から組み立てない。編集欄は `lessonDraft` だけをソースにする。
