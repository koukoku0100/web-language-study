# 画面設計書: 問題集管理

| 項目 | 内容 |
| --- | --- |
| ファイル名 | `WELG0130_問題集管理.md` |
| 画面ID | WELG0130 |
| 対応 | `管理画面モック.pdf` 4ページ |
| 画面名 | 問題集管理 |
| 技術 | React 18、関数コンポーネント、Hooks、Next.js 14（App Router）、Redux、TypeScript |

この文書だけで、問題集管理の見た目と、問題一覧のデータ描画を実装できること。登録、CSV、保存、公開の処理は対象外。

## 印の意味

- 【不明】PDFにも別要件にも確定値がない。実装で文言や動作を足さない。
- 【仮】画面を置くためにこちらの設計で決めた値。PDFには無い。

## 作る範囲

- 右側だけを表示する。画面IDは `WELG0130`。左側の紺領域は描画しない。
- 絞り込み欄、問題一覧、編集欄を表示する。
- 一覧、絞り込みの選択肢、編集欄の選択肢は、渡された配列の件数だけ描画する。
- 編集欄の文字は画面内の state で変更できる。保存ボタンでは store へ書き戻さない。

## 作らない範囲

- CSV 取込、問題追加、下書き保存、公開の処理と遷移。
- 絞り込みや検索で一覧を減らす処理。一覧は渡された配列をそのまま全部出す。
- 行クリックで編集対象を切り替える処理。
- ラジオボタンで正解を付け替える処理。正解の見た目はデータのフラグで描画するだけ。
- 穴埋め以外の形式専用の編集UI。PDFにある編集欄は Q-0103 の1件だけ。

## Redux

slice 名は `questionBank`。初期 state にサンプルを置く。reducer は作らない。絞り込み、追加、CSV、保存、公開、正解変更、行選択の action は作らない。

編集欄の文字変更は `QuestionBankView` の `useState` に保持し、初期値は `questionDraft` のコピー。保存ボタンでは slice へ戻さない。

選択肢の配列もこのローカル state に含める。文字の変更は要素ごとに反映してよい。件数の増減ボタンは PDF に無いので作らない。件数を変えるときは Redux の初期配列を変える。

## 描画ルール

| 領域 | ソース | 増減 |
| --- | --- | --- |
| コース、形式、状態 | それぞれの options 配列 | `option` を件数分出す |
| 問題表 | `questions` | 行を件数分出す |
| 選択肢 | `questionDraft.choices` | ラジオと入力欄を件数分出す。4件固定にしない |

表の列は次の順で固定する。列自体をデータ化するかは【不明】なので、列の増減はしない。

| 列 | セルの中身 |
| --- | --- |
| ID | `id` |
| 問題文 | `prompt` |
| レッスン | `{lessonOrder} {lessonName}`。間は半角スペース |
| 形式 | 上の対応表 |
| 状態 | 状態バッジ |
| 更新日 | `updatedOn` |

件数表示は、`questions.length` が 1 以上のときだけ次の文言にする。

```text
1〜{questions.length}件を表示
```

0件のときの文言は【不明】。件数テキストは出さない。ヘッダ行は残す。ページ番号、前後ページのボタンは PDF に無いので作らない。

編集欄の見出しは次の形。

```text
問題を編集（{questionId}）
```

選択肢の記号は `choice.id` をそのまま出す。A、B、C、D という採番規則は【不明】。`id` を加工して記号を作らない。

ラジオは `checked={choice.selectedAsCorrect}`。`name` は同一グループにする。`onChange` は付けない。制御コンポーネントの警告を避けるため、ラジオは `readOnly` ではなく、クリックしても選択が動かないよう `onMouseDown` と `onClick` で `preventDefault` してよい。選択結果は初期データのまま維持する。

問題文と解説は `textarea`。行数は【不明】。【仮】問題文 4 行、解説 3 行。選択肢の文言は単一行の `input`。

## 受け入れ条件

- この画面のコンポーネントは `AdminShell` を描画しない。左側は `(console)/layout.tsx` に残る。
- この画面の配列を増減しても、`AdminShell` は再レンダーしない。
- 左側に、管理者名の上の 1px の線（`#374051`）と、ログアウトの下線がある。
- `/questions` で「問題集」が選択状態になる。
- 初期データの6行、Q-0103 の選択背景、編集欄の解説と4つの選択肢が見える。A のラジオだけ塗られている。
- `questions` の件数に合わせて行と「1〜N件を表示」が変わる。0件では件数テキストが消える。
- `choices` を2件にするとラジオが2つ、5件にすると5つになる。
- 絞り込みの select を変えても行数は変わらない。
- ラジオを押しても、塗られている位置は変わらない。
- 問題文や選択肢の文字は変更できるが、保存系ボタンを押しても Redux の配列は変わらない。
- CSV、追加、保存、公開、メニュー、ログアウトを押しても遷移しない。
