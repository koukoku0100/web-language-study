# 画面設計書: 問題集管理

| 項目 | 内容 |
| --- | --- |
| ファイル名 | `WELG0130_問題集管理.md` |

| 技術 | React 18、関数コンポーネント、Hooks、Next.js 14（App Router）、Redux、TypeScript |

この文書だけで、問題集管理の見た目と、問題一覧のデータ描画を実装できること。登録、CSV、保存、公開の処理は対象外。

この画面の色、余白、文字サイズ、太さは、この設計書の数値を使う。共通部品に付け替えるときは `doc/共通部品.md` に従い、部品とこの画面の両方で指定しているプロパティは、そこに書いた CSS 変数へこの設計書の数値を代入する。部品が指定していない幅や位置は、この設計書の数値を通常の CSS で書く。表ヘッダは、共通部品の既定である上下中央のままにする。

## 印の意味

- 【不明】PDFにも別要件にも確定値がない。実装で文言や動作を足さない。
- 【仮】画面を置くためにこちらの設計で決めた値。PDFには無い。

## 作る範囲

- 右側だけを表示する。画面IDは `WELG0130`。左側の紺領域は描画しない。
- 絞り込み欄、問題一覧、編集欄を表示する。
- 一覧、コースと形式の選択肢、編集欄の選択肢は、渡された配列の件数だけ描画する。状態の選択肢は共通の `LessonStatus` から作り、`private`（非公開）は出さない。先頭に「すべて」を置く。
- 編集欄の文字と、絞り込み欄の選択表示は、画面内の state で変更できる。保存ボタンでは store へ書き戻さない。
- 正解のラジオは画面内の state で付け替える。1件選ぶと、ほかの選択は外れる。正解は1件だけの想定。

## 作らない範囲

- CSV 取込、問題追加、下書き保存、公開の処理と遷移。
- 絞り込みや検索で一覧を減らす処理。一覧は渡された配列をそのまま全部出す。select の表示が変わっても、件数も行の中身も変えない。
- 行クリックで編集対象を切り替える処理。
- 正解を store へ書き戻す処理。画面上のラジオの付け替えは作る。
- 穴埋め以外の形式専用の編集UI。PDFにある編集欄は Q-0103 の1件だけ。

## 見た目の暫定値

PDF 4ページ目の画像と、文字の位置・サイズから測った値。実装で合わせるための暫定であり、指定値ではない。1px 単位に丸めている。小数だった実測は、表の実測列に残す。

基準は、モック画像の 1080×975 をそのまま px とみなす。

フォントファミリー名は取れていない。他の画面と同じく、ページの Arial を継承する【仮】。

太字（700）にする。文字サイズは変えない。

- タイトル「問題集管理」

## 型

`LessonStatus` はこの画面で定義しない。`doc/WELG0120_コース・レッスン管理.md` の共通定義（`src/features/lesson-status/lessonStatus.ts`）を使う。値を足すと、一覧の状態と、この画面の絞り込み「状態」に足される。ただし絞り込みは `private`（非公開）を出さない。

絞り込み「状態」の値の型は `QuestionStatusFilter`。`LessonStatus` に `"all"` を足したもの。`"all"` は `LessonStatus` に入れない。全件を意味する。

更新日は `src/features/calendar-date/calendarDate.ts` の `CalendarDate`。`year`、`month`、`day` は数。`Date` にはしない。表示は `formatMonthDay` で、年を出さず `10/09` のように、2桁の月と 2桁の日を `/` でつなぐ。画面に年が無かったので、年は【仮】`2026`。

```ts
import type { CalendarDate } from "@/features/calendar-date/calendarDate";
import type { LessonStatus } from "@/features/lesson-status/lessonStatus";

export type QuestionFormat = "multiple_choice" | "fill_in_blank";

export type QuestionStatusFilter = LessonStatus | "all";

export type SelectOption = {
  id: string;
  label: string;
};

export type QuestionListItem = {
  id: string;
  prompt: string;
  lessonOrder: number;
  lessonName: string;
  format: QuestionFormat;
  status: LessonStatus;
  updatedOn: CalendarDate;
  selected: boolean;
};

export type QuestionChoice = {
  id: string;
  text: string;
  selectedAsCorrect: boolean;
};

export type QuestionDraft = {
  questionId: string;
  prompt: string;
  explanation: string;
  choices: QuestionChoice[];
};

export type QuestionBankState = {
  screenId: "WELG0130";
  showSampleDataBadge: boolean;
  title: string;
  description: string;
  courseOptions: SelectOption[];
  selectedCourseId: string;
  formatOptions: SelectOption[];
  selectedFormatId: string;
  selectedStatusId: QuestionStatusFilter;
  questions: QuestionListItem[];
  questionDraft: QuestionDraft;
};
```

## Redux

slice 名は `questionBank`。初期 state にサンプルを置く。reducer は作らない。絞り込み、追加、CSV、保存、公開、行選択の action は作らない。正解の付け替えも reducer にはしない。

編集欄の文字、絞り込みの3つの選択、選択肢の配列は、`QuestionBankView` の `useState` に保持する。初期値は slice のコピー。保存ボタンでは slice へ戻さない。

選択肢の文字の変更は要素ごとに反映してよい。件数の増減ボタンは PDF に無いので作らない。件数を変えるときは Redux の初期配列を変える。ラジオを押したときは、押した1件だけ `selectedAsCorrect` を `true` にし、同じ配列のほかは `false` にする。

## 描画ルール

| 領域 | ソース | 増減 |
| --- | --- | --- |
| コース、形式 | それぞれの options 配列 | `option` を件数分出す |
| 状態 | 共通の `LessonStatus`。先頭に `"all"`。`private` は除外 | `option` をその件数分出す |
| 問題表 | `questions` | 行を件数分出す |
| 選択肢 | `questionDraft.choices` | ラジオと入力欄を件数分出す。4件固定にしない |

表の列は次の順で固定する。列自体をデータ化するかは【不明】なので、列の増減はしない。

| 列 | セルの中身 |
| --- | --- |
| ID | `id` |
| 問題文 | `prompt` |
| レッスン | `{lessonOrder} {lessonName}`。間は半角スペース |
| 形式 | 上の対応表 |
| 状態 | 状態バッジ |
| 更新日 | `formatMonthDay(updatedOn)` |

件数表示は、`questions.length` が 1 以上のときだけ次の文言にする。

```text
1〜{questions.length}件を表示
```

0件のときの文言は【不明】。件数テキストは出さない。ヘッダ行は残す。ページ番号、前後ページのボタンは PDF に無いので作らない。

編集欄の見出しは次の形。

```text
問題を編集（{questionId}）
```

選択肢の記号は `choice.id` をそのまま出す。A、B、C、D という採番規則は【不明】。`id` を加工して記号を作らない。

ラジオは `checked={choice.selectedAsCorrect}`。`name` は同一グループにする。`onChange` で、押した `id` だけ `selectedAsCorrect` を `true` にし、ほかは `false` にする。`preventDefault` で選択を止めない。保存ボタンでは、この結果を slice へ戻さない。

問題文と解説は `textarea`。問題文は高さ 72px で 4 行【仮】、解説は高さ 60px で 3 行【仮】。右下のリサイズは出さない【仮】。選択肢の文言は単一行の `input`。

## 受け入れ条件

- この画面のコンポーネントは `AdminShell` を描画しない。左側は `(console)/layout.tsx` に残る。
- この画面の配列を増減しても、`AdminShell` は再レンダーしない。
- 左側に、管理者名の上の 1px の線（`#374051`）と、ログアウトの下線がある。
- `/questions` で「問題集」が選択状態になる。
- 初期データの6行、Q-0103 の選択背景、編集欄の解説と4つの選択肢が見える。A のラジオだけ塗られている。
- `questions` の件数に合わせて行と「1〜N件を表示」が変わる。0件では件数テキストが消える。
- `choices` を2件にするとラジオが2つ、5件にすると5つになる。
- 画面幅を 1080px より狭くしても、カードは 838px のままである。横スクロールバーは出ない。縦のスクロールは画面全体のバーだけである。
- 絞り込みの select を変えても行数は変わらない。
- ラジオを押すと、押した1件だけが塗られ、それまで塗られていたものは外れる。保存ボタンを押しても Redux の正解は変わらない。
- 問題文や選択肢の文字は変更できるが、保存系ボタンを押しても Redux の配列は変わらない。
- CSV、追加、保存、公開、ログアウトを押しても遷移しない。メニューを押すと、仮ルートへ移動する。
