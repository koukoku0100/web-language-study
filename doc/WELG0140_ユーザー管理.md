# 画面設計書: ユーザー管理

| 項目 | 内容 |
| --- | --- |
| ファイル名 | `WELG0140_ユーザー管理.md` |
| 画面ID | WELG0140 |
| 対応 | `管理画面モック.pdf` 5ページ |
| 画面名 | ユーザー管理 |
| 技術 | React 18、関数コンポーネント、Hooks、Next.js 14（App Router）、Redux、TypeScript |

この文書だけで、ユーザー管理の見た目と、学習者一覧のデータ描画を実装できること。検索の実行と利用停止の処理は対象外。

この画面の色、余白、文字サイズ、太さは、この設計書の数値を使う。共通部品に付け替えるときは `doc/共通部品.md` に従い、部品とこの画面の両方で指定しているプロパティは、そこに書いた CSS 変数へこの設計書の数値を代入する。部品が指定していない幅や位置は、この設計書の数値を通常の CSS で書く。表ヘッダは、共通部品の既定である上下中央のままにする。

## 印の意味

- 【不明】PDFにも別要件にも確定値がない。実装で文言や動作を足さない。
- 【仮】画面を置くためにこちらの設計で決めた値。PDFには無い。

## 作る範囲

- 右側だけを表示する。画面IDは `WELG0140`。左側の紺領域は描画しない。
- 検索欄、母語、状態、検索ボタン、学習者一覧を表示する。
- 一覧と、母語・状態の選択肢は、渡された配列の件数だけ描画する。
- 検索欄の文字と、母語・状態の選択表示は、画面内の state で変更できる。store へ書き戻さない。

## 作らない範囲

- 検索ボタン、母語、状態で一覧を減らす処理。一覧は渡された配列をそのまま全部出す。select の表示が変わっても、件数も行の中身も変えない。
- 利用停止、利用再開、行の詳細、編集。画面説明に「利用停止の操作」とあるが、一覧上の停止ボタンは PDF に無い。ボタンを新たに足さない。
- ページ送り。

## 型

日付は `src/features/calendar-date/calendarDate.ts` の `CalendarDate` で持つ。`year`、`month`、`day` は数。月と日は 1 始まり。`Date` にはしない。

登録日の表示は `formatYearMonthDay` で、`2026/09/03` のように、年、2桁の月、2桁の日を `/` でつなぐ。最終学習日の表示は `formatMonthDay` で、`10/12` のように、年を出さず、2桁の月と 2桁の日を `/` でつなぐ。画面に年が無かった最終学習日の年は【仮】`2026`。

```ts
export type CalendarDate = {
  year: number;
  month: number;
  day: number;
};

export function formatYearMonthDay(date: CalendarDate): string;
export function formatMonthDay(date: CalendarDate): string;

export type AccountStatus = "active" | "suspended";

export type SelectOption = {
  id: string;
  label: string;
};

export type Learner = {
  id: string;
  name: string;
  email: string;
  nativeLanguage: string;
  registeredOn: CalendarDate;
  progressRate: number;
  lastStudiedOn: CalendarDate;

export type LearnerAdminState = {
  screenId: "WELG0140";

  title: string;

  searchPlaceholder: string;
  nativeLanguageOptions: SelectOption[];
  selectedNativeLanguageId: string;
  statusOptions: SelectOption[];

```

## Redux

slice 名は `learnerAdmin`。初期 state にサンプルを置く。reducer は作らない。検索、利用停止、ページ変更の action は作らない。

一覧は `learners` をそのまま `map` する。検索欄の入力、母語の選択、状態の選択は、`LearnerAdminView` の `useState` に保持する。検索欄の初期値は空文字。母語と状態の初期値は、slice の `selectedNativeLanguageId` と `selectedStatusId` のコピー。どれも slice へ戻さない。store の `learners` は変えない。

## 描画ルール

| 領域 | ソース | 増減 |
| --- | --- | --- |
| 母語 | `nativeLanguageOptions` | `option` を件数分出す |
| 状態 | `statusOptions` | `option` を件数分出す |
| 学習者表 | `learners` | 行を件数分出す。8行固定にしない |

表の列順は固定。列の増減はしない。ヘッダに出す文言は、次の列名そのままにする。

| 列 | セル |
| --- | --- |
| ユーザー名 | `name` |
| メールアドレス | `email` |
| 母語 | `nativeLanguage` |
| 登録日 | `formatYearMonthDay(registeredOn)` |
| 学習の進み具合 | バーと `{progressRate}%` |
| 最終学習日 | `formatMonthDay(lastStudiedOn)` |
| 状態 | 状態バッジ |

件数表示は `learners.length` が 1 以上のときだけ、次の文言にする。

```text
1〜{learners.length}件を表示
```

0件の文言は【不明】。件数テキストは出さず、ヘッダは残す。ページ送りは作らない。

検索欄の文字、母語、状態の選択表示は変えられる。変えても `learners` の描画結果は変えない。検索ボタンも同じ。

行クリックの動作は【不明】。行に `onClick` は付けない。

## 受け入れ条件

- この画面のコンポーネントは `AdminShell` を描画しない。左側は `(console)/layout.tsx` に残る。
- この画面の配列を増減しても、`AdminShell` は再レンダーしない。
- 左側に、管理者名の上の 1px の線（`#374051`）と、ログアウトの下線がある。
- `/users` で「ユーザー」が選択状態になる。
- 初期データの8行、進捗の幅、Learner 006 の「停止中」が見える。
- `learners` を10件にすると10行になり、件数表示が「1〜10件を表示」になる。0件では行と件数テキストが消える。
- `nativeLanguageOptions` を増やすと、母語の select の候補だけが増える。一覧の行数は変わらない。
- 母語または状態の select を変えても行数は変わらない。
- 検索欄へ文字を入れても、検索ボタンを押しても、行は減らない。
- 一覧に利用停止ボタンや編集ボタンが無い。
- ログアウトを押しても遷移しない。メニューを押すと、仮ルートへ移動する。
