| 項目 | 内容 |

| 技術 | React 18、関数コンポーネント、Hooks、Next.js 14（App Router）、Redux、TypeScript |

この文書だけで、管理者・ロール管理の見た目と、権限表・管理者一覧のデータ描画を実装できること。権限の変更、管理者の追加、編集の処理は対象外。

## 印の意味

- 【不明】PDFにも別要件にも確定値がない。実装で文言や動作を足さない。
- 【仮】画面を置くためにこちらの設計で決めた値。PDFには無い。

## 作る範囲

- 右側だけを表示する。画面IDは `WELG0150`。左側の紺領域は描画しない。
- ロール別の権限表と、管理者アカウント表を表示する。
- 権限の行、ロールの列、管理者の行は、渡された配列の件数だけ描画する。

## 作らない範囲

- 権限の可と不可を切り替える処理。チェックボックスは PDF に無いので置かない。
- 管理者を追加する処理と、編集ボタンの遷移。
- 権限表が案であることの確定作業。見出しと補足文を表示するだけ。

権限表が上、管理者表が下。「管理者を追加」は管理者カードの右上。青背景、白文字。

## 見た目の暫定値

PDF 6ページ目の画像と、文字の位置・サイズから測った値。実装で合わせるための暫定であり、指定値ではない。1px 単位に丸めている。

このページのキャンバスは 595.28×841.89 で、1ページ目の 1080px 幅より小さい。同じ UI を縮小している。倍率は 1080 / 595.28 = 1.815。以下の px は、ページ上の座標と文字サイズに 1.815 を掛けて、1080px 幅の画面に揃えた値。高さは換算後約 1528px。

左側の紺領域は WELG0110 と同じ。このページでも、換算後のサイドバー幅は 180px、背景 #1C2431、本文左端 211px だった。

管理者名の上に、高さ 1px の直線を付ける。色は `#374051`。左 12px、右端 168px。選択中メニューと同じ左右位置。名前の上端より 15px 上。文字には重ねない。

ログアウトの文字に下線を付ける。`text-decoration: underline`。色は `#CED6E3` のまま。太さは通常。

左側の間隔は、この画面でも次のとおり。

## 描画ルール

| 領域 | ソース | 増減 |
| --- | --- | --- |
| 権限表の列 | `roleColumns` | 先頭の「操作」列のあとに、ロールを件数分並べる |
| 権限表の行 | `permissionRows` | 行を件数分出す |
| 管理者表 | `accounts` | 行を件数分出す。各行に編集ボタンを1つ出す |

権限のヘッダは、固定の「操作」のあとに `roleColumns` を `map` する。3列固定にしない。

各行の各ロール列は、`cells` から `roleId` が一致する要素を探してバッジを出す。一致する要素が無いときの表示は【不明】。空セルにする。同じ `roleId` が複数あるときの優先は【不明】。先に見つかった1件を出す。

0件の案内文は【不明】。権限行が0件ならヘッダだけ残す。管理者が0件ならヘッダと「管理者を追加」だけ残す。ロール列が0件なら「操作」列だけ残す。

管理者表の列順は固定。

| 列 | セル |
| --- | --- |
| 名前 | `name` |
| メールアドレス | `email` |
| ロール | `roleName` |
| 状態 | 状態バッジ |
| 操作 | ボタン「編集」 |

編集ボタンのラベルは固定文言。アカウントごとにラベルを変えない。

この画面に「1〜N件を表示」は PDF に無い。件数テキストは出さない。

権限セルにカーソルを合わせた説明や、クリックでの変更は【不明】。セルはボタンにしない。

## 受け入れ条件

- この画面のコンポーネントは `AdminShell` を描画しない。左側は `(console)/layout.tsx` に残る。
- この画面の配列を増減しても、`AdminShell` は再レンダーしない。
- 左側に、管理者名の上の 1px の線（`#374051`）と、ログアウトの下線がある。
- `/admins` で「管理者・ロール」が選択状態になる。
- 初期データの権限8行、ロール3列、管理者4行が見える。サポート D は「停止中」。
- `roleColumns` を2件にすると権限表のロール列が2列になる。補足文は初期文言のまま変えない。
- `permissionRows` を増やすと行が増える。セルの可と不可はデータどおり。
- `accounts` を5件にすると5行になり、編集ボタンも5つになる。0件では編集ボタンが消える。
- 可と不可はバッジであり、クリックしても値は変わらない。
- 管理者を追加、編集、メニュー、ログアウトを押しても遷移しない。
