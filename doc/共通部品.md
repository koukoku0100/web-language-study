# 設計書: 共通部品

| 項目 | 内容 |
| --- | --- |
| ファイル名 | `共通部品.md` |
| 画面ID | 無し。画面ではなく、複数画面で分かれている見た目の部品 |
| 対応 | 既存の画面実装。PDF のページは割り当てない |
| 技術 | React 18、関数コンポーネント、Hooks、Next.js 14（App Router）、TypeScript。スタイルは CSS Modules |

この文書だけで、共通部品のファイルを追加できること。各画面をこの部品へ付け替える作業は、この文書の対象外。付け替えるとき、各画面の見た目の数値は、その画面設計書を優先する。

Material UI と shadcn は入れない。依存関係にも CSS の仕組みにも足さない。

## 印の意味

- 【不明】既存の画面にも画面設計書にも確定値がない。実装で文言や動作を足さない。
- 【仮】共通部品の既定としてこちらの設計で選んだ値。画面ごとに数値が違うとき、多い側の値を既定にし、違う画面は上書きに回す。

## 方針

共通部品は、今の画面にすでにある見た目だけをまとめる。新しい画面の形は作らない。

部品は Redux を読まない。表示する文字、配列、選択中の値は、呼び出し元の画面が渡す。

ホバー色、フォーカス色、アニメーションは【不明】。足さない。

ボタンと入力は、画面が処理を渡したときだけその処理を実行する。共通部品の中で、遷移、保存、絞り込み、検証を足さない。

### 上書き

画面と部品の両方が指定するプロパティは、CSS 変数にする。部品の CSS は、そのプロパティを直接書かない。`var(--名前, 既定値)` と書き、既定値はフォールバックに置く。部品自身は、その変数へ代入しない。

画面は、部品から受け取った `className` に、変えたい変数だけを代入する。部品が代入していないプロパティなので、CSS の読み込み順では勝敗が決まらない。

変数は、そのプロパティを描画する要素の `className` で代入する。親要素に代入した変数は、子へ継承される。

部品が最初から指定しないプロパティは、変数にしない。画面の `className` に、通常の CSS プロパティとして書く。幅、位置、`white-space` がこれにあたる。

太さの変数は、通常を `400`、太字を `700` で代入する。

| 部品 | 変数 | 既定 |
| --- | --- | --- |
| 説明 | `--page-description-font-size` | `11px` |
| 説明 | `--page-description-margin-top` | `10px` |
| サンプルデータバッジ | `--sample-badge-padding-inline` | `9px` |
| サンプルデータバッジ | `--sample-badge-font-weight` | `400` |
| サンプルデータバッジ | `--sample-badge-color` | `#864704` |
| ボタン | `--button-height` | `32px` |
| ボタン | `--button-padding-inline` | `15px` |
| ボタン | `--button-font-size` | `11px` |
| ボタン | `--button-font-weight` | `400` |
| ラベル | `--field-label-margin-bottom` | `8px` |
| テキスト入力 | `--text-input-color` | `#1B2430` |
| テキスト入力 | `--text-input-line-height` | `14px` |
| テキスト入力 | `--text-input-padding` | `8px 10px` |

状態バッジは、tone ごとのクラスが `var(--名前, その tone の既定)` を使う。tone のクラスも、変数へ代入しない。

`className` は、部品の既定クラスと同じ要素に足す。部品の内側のクラス名を、画面側から指定しない。

## 作る範囲

次の部品を、新しい共通ファイルとして作れる状態にする。

- ページのタイトルと説明
- サンプルデータバッジ
- 白カード
- カード見出し
- 主ボタンと副ボタン
- ラベル、テキスト入力、選択欄、テキストエリア
- 表のヘッダ行、データ行、セル
- 状態バッジ
- 進捗バー
- 件数表示

## 作らない範囲

- 各画面の `View`、slice、ページを、この部品を使う形へ書き換えること。
- 各画面設計書に書いてある見た目の数値を変えること。
- `AdminShell` の作り直し。左側の紺領域は、いまの共通のままにする。
- Material UI、shadcn、その他の見た目用ライブラリの追加。
- 画面に1つしか無い部品。WELG0130 のラジオ、WELG0150 の「不可」、WELG0120 の動画プレビュー、WELG0110 の指標数値、WELG0120 の紐づく問題集バッジ、WELG0120 のレッスン行は、共通ファイルにしない。
- ボタンの並び。間隔が画面ごとに違うので、並びは各画面に残す。
- API 通信、保存、画面遷移、権限による出し分け。

## 状態バッジ

| `draft` | 下書き | 17px | `8px`【仮】 | `#EDF0F5` | `#454D5A`【仮】 | 太字 |
| `private` | 非公開 | 17px | `8px`【仮】 | `#FFF0DD` | `#8E4601` | 太字 |
| `active` | 利用中 | 15px | `6px`【仮】 | `#E9EDF8` | `#1F3E70`【仮】 | 太字 |
| `suspended` | 停止中 | 15px | `6px`【仮】 | `#FFF0DD`【仮】 | `#834A05`【仮】 | 太字 |
| `allowed` | 可 | 17px | `9px` | `#E9EDF8` | `#1F3A76` | 通常 |

## 進捗バー

| 引数 | 役割 |
| --- | --- |
| `variant` | `fluid` または `fixed` |
| `rate` | 塗りの幅。トラックに対する百分率。画面が渡す |

共通部品では 0 にも 100 にも丸めない。表示する数の計算もしない。

| 項目 | `fluid`（WELG0110） | `fixed`（WELG0140） |
| --- | --- | --- |
| トラックの幅 | 親の幅 | 93px |
| 高さ | 6px | 6px |
| トラックの背景 | `#DFEEFF` | `#E6EBF1` |
| トラックの角丸 | 無し | 2px |
| はみ出し | 指定しない | 隠す |
| 塗り | `#2B4C9B`、高さ 6px | `#2B4C9B`、高さ 6px、角丸 2px |

`fixed` で率がトラックを超える分は、トラックの `overflow: hidden` で隠す。この部品に、画面ごとの上書き変数は無い。

## 件数表示

引数は `count` と `className`。`count` は、画面が配列の長さを渡す。1 以上のときだけ出す。0 のときは何も出さない。文言は `1〜{件数}件を表示`。

| 項目 | 既定 |
| --- | --- |
| 上余白 | `var(--list-count-margin-top, 15px)` |
| 文字 | 9px、通常、`#5B6675`、行の高さ 9px |

WELG0140 は `className` で `--list-count-margin-top: 12px` を代入する。WELG0150 には件数表示が無いので、この部品を置かない。
